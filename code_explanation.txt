爆砕！巨大豆腐タイムアタック — コード解説
========================================

1. ゲームの概要
---------------
このゲームは、通常豆腐から始まり、個別の撃破タイムに応じて次の豆腐の強さが変わる全3ステージのブラウザーゲームです。
3D描画にはThree.js、画面レイアウトにはTailwind CSS、効果音にはWeb Audio APIを使用しています。
ゲーム画面はHTML、見た目の細かな演出はCSS、ゲーム処理と3D制御はJavaScriptに分けています。

主なファイル:
  index.html          画面の構造、UI部品、外部ライブラリと各ファイルの読み込み
  code_artifact.css   画面揺れ、フラッシュ、ボタン、フィーバーなどのスタイル
  code_artifact.js    効果音、3Dシーン、ゲーム進行、入力、アニメーション


2. HTML — index.html
--------------------
HTMLはゲーム画面を構成する部品を定義します。ゲームの数値や状態を変更する処理はJavaScript側にあります。

head内の読み込み:
  - Tailwind CSS CDN: 余白、色、配置、文字サイズなどのユーティリティクラスを提供します。
  - Three.js CDN: ブラウザー上で3Dオブジェクトを描画するライブラリです。
  - Google Fonts: Dela Gothic OneとM PLUS Rounded 1cを読み込みます。
  - code_artifact.css: 独自のアニメーションとスタイルを読み込みます。

body内の主な要素:
  - canvas-container: Three.jsが生成する3Dキャンバスを配置する領域です。
  - overlay-flash: 強い攻撃時にフラッシュ要素を一時的に追加する場所です。
  - 上部UI: 戦闘時間の合計、ステージ番号、対戦中の豆腐名とHP、コンボ数、フィーバーゲージを表示します。
  - cutin-container: 必殺技やフィーバー開始時のテキスト演出を表示します。
  - modal-screen: ゲーム開始、次ステージへの挑戦確認、クリア後の結果パネルを表示します。
  - 下部UI: 溜め攻撃ボタンと3種類の通常攻撃ボタンです。

画面の各部品にはidが設定されています。JavaScriptはdocument.getElementById()で対象を取得し、
テキスト、幅、表示状態、CSSクラスを更新します。
ファイル末尾でcode_artifact.jsを読み込み、画面要素をHTML上に用意してからイベントを登録します。


3. CSS — code_artifact.css
--------------------------
Tailwind CSSで表現しにくい、ゲーム独自の動きや装飾を定義しています。

主なスタイル:
  - body: フォント、背景色、スクロール抑制、タッチ操作の基本設定です。
  - shake-sm / shake-lg: 攻撃の強さに合わせて画面を小さく、または大きく揺らします。
  - impact-flash: 強い攻撃の直後に画面全体を白く光らせます。
  - btn-push: ボタンを押したときに縮小・明るくする押し込み表現です。
  - fever-bg: フィーバー中の背景グローと色変化を表現します。
  - hit-stopped: アニメーションを一時停止させるためのクラスです。

@keyframesはアニメーションの途中経過を定義し、各クラスがそのアニメーションを適用します。
HTMLにあるTailwindのクラスと組み合わせて画面全体の見た目を作ります。


4. JavaScript — code_artifact.js
--------------------------------
JavaScriptは大きく、効果音、3D描画、ゲーム状態とルール、入力処理、毎フレームの描画に分かれています。

4-1. 効果音エンジン SoundEngine
  - init(): AudioContextを作成または再開します。ブラウザーの制限に対応するため、
    ゲーム開始時に呼び出します。
  - playPurun(): 正弦波の周波数と音量を変化させ、小さな打撃音を合成します。
  - playHit(heavy): ノイズと低い音を重ね、通常または強い攻撃音を作ります。
  - playCharge(): 上昇する鋸歯状波で溜め音を作ります。
  - playDestroy(): 長めのノイズを使い、豆腐撃破時の爆発音を作ります。

音声ファイルを再生しているのではなく、Web Audio APIの発振器、ノイズ、フィルター、音量制御を
組み合わせて音を生成しています。

4-2. Three.jsの3Dシーン
  init3D()がシーン、カメラ、レンダラー、ライト、床、豆腐、トッピング、プレイヤーを作成します。
  画面サイズが変わったときはonWindowResize()でカメラとレンダラーの大きさを更新します。

  - createTofu(): 分割数の多いBoxGeometryを作ります。頂点数に余裕を持たせることで、
    後から豆腐の表面を揺らせるようにしています。生成時の頂点位置はoriginalVerticesに保存します。
  - createToppings(): 醤油の薄い面と複数のネギを作り、グループ化します。
  - createPlayer(): 赤い球体をプレイヤーとして作成します。
  - spawnImpactParticles(): 豆腐の破片、ネギ、醤油の粒を作り、初速や回転速度を設定してシーンに追加します。

4-3. ゲーム状態とタイマー
  - NORMAL_TOFU: 必ず最初に登場する通常豆腐（600,000 HP）です。
  - STAGE_TWO_TIERS: 通常豆腐を倒すまでの個別タイムで第2ステージの相手を選びます。
    15秒以内は鉄豆腐（2,400,000 HP）、25秒以内はプラスチック豆腐（1,800,000 HP）、
    40秒以内は胡麻豆腐（1,200,000 HP）、それより遅い場合は卵豆腐（900,000 HP）です。
  - FINAL_BOSS_TIERS: 第2ステージの個別タイムにより最終ボスのHPを決めます。
    20秒以内は覚醒形態（4,000,000 HP）、40秒以内は真の力（3,200,000 HP）、
    それより遅い場合も最強豆腐（2,600,000 HP）が最後に登場します。
  - STAGE_TOTAL: ステージ数です。現在は3です。
  - stageSequence: このプレイで実際に登場する3体を保持します。
  - currentStageIndex / currentStage: 現在のステージ番号と設定を保持します。
  - currentHp: 現在のHPです。
  - isPlaying / isStageTransitioning: ゲーム中か、次の挑戦確認中かを示します。
  - stageStartTime / elapsedTime: 現在の豆腐の個別タイムと、挑戦中のステージの合計時間を管理します。
  - combo: 連続攻撃回数です。
  - feverGauge / isFever: フィーバーゲージとフィーバー中かどうかを管理します。
  - bestTime: 全ステージ合計の自己ベストです。旧1ステージ版とは別のキーでlocalStorageに保存します。

  startGame()は通常豆腐から開始し、各ステージのタイムを初期化します。
  loadStage()は選ばれた豆腐のHP、名前、表示、色・材質・大きさを反映します。
  updateTimer()はrequestAnimationFrame()で繰り返し呼ばれ、戦闘中だけ時間を加算します。
  ステージ間の確認画面を開いている間はタイマーが止まり、「挑戦する！」を押すと次の個別タイムが始まります。
  selectTier()はクリアタイムに合う豆腐設定を閾値リストから選びます。
  formatTime()はミリ秒を「分:秒.ミリ秒」の形式に変換します。

4-4. 攻撃とダメージ計算
  SKILLSに攻撃ごとの基本ダメージと種類を定義しています。
    体当たり:         18,000
    スライディング:   28,000
    ドロップキック:   45,000（強攻撃）
    最大溜め攻撃:    150,000（強攻撃）

  attack()がダメージ処理の中心です。攻撃中でない場合は何もせず、次の式でダメージを計算します。

    コンボ補正 = 1 + min(コンボ数 × 0.02, 1.5)
    フィーバー補正 = フィーバー中なら2.5、それ以外なら1
    最終ダメージ = floor(基本ダメージ × コンボ補正 × フィーバー補正)

  HPは0未満にならないようにし、updateHpUI()で現在の豆腐の最大HPを基準にバーと数値を更新します。
  攻撃のたびにコンボ数が増え、フィーバー中でなければゲージが4ポイント増えます。
  ゲージが100に達するとactivateFever()が呼ばれ、5秒間ダメージが2.5倍になります。

  強攻撃は、通常攻撃より大きな豆腐の揺れ、画面揺れ、破片、カットインを発生させます。
  現在の豆腐のHPが0になるとdefeatCurrentStage()が呼ばれます。個別タイムを確定して次の相手を選び、
  「〇〇豆腐登場！！」と「挑戦する！」ボタンの確認画面を表示します。確認中は攻撃もタイマーも止まります。
  startNextStage()はボタンを押したときに次の豆腐を表示し、新しい個別タイムを開始します。
  最終ステージを倒したときだけfinishGame()が呼ばれ、ゲーム全体の結果表示に進みます。

4-5. UI表示と演出
  - updateHpUI(): HPバーの幅とHP数値を更新します。白い残像バーは少し遅れて追従します。
  - updateComboUI(): コンボ数を表示し、2秒間攻撃がなければコンボ表示を消します。
  - activateFever(): 背景をフィーバー表示にし、ゲージを5秒かけて減らします。
  - triggerScreenShake(): CSSクラスで画面を揺らします。強攻撃ではフラッシュも追加します。
  - showCutin(): 必殺技名などを拡大表示し、一定時間後に縮小して隠します。
  - animatePlayerAttack(): プレイヤーを短時間豆腐側へ移動させて戻します。

  finishGame()は全ステージの合計クリアタイムによってランクを決めます。
    40秒未満: S
    60秒未満: A
    90秒未満: B
    それ以外: C

  戦闘時間の合計が自己ベストより短い場合はlocalStorageの「tofu_campaign_best_time」を更新します。
  最強豆腐を倒した後にだけ、結果パネルへ合計タイム、ランク、新記録を表示します。

4-6. 入力とボタン
  画面上のボタンにはclick、mouse、touchのイベントを登録しています。
  キーボードでは次のキーが使えます。
    Zまたは左矢印: 体当たり
    Xまたは右矢印: スライディング
    Cまたは上矢印: ドロップキック
    Spaceを押している間: 溜め攻撃

  溜め攻撃は700ミリ秒以上押すと最大溜め攻撃になります。700ミリ秒未満で離すと、
  体当たりの基本ダメージの1.5倍の攻撃になります。
  キーボードのkeydown.repeatを無視することで、キーを押しっぱなしにしたときの連続発火を防ぎます。

  全ステージクリア後の共有ボタンは戦闘時間の合計とランクを含む文章を作り、Xの投稿画面を開きます。

4-7. アニメーションループ
  animate()はrequestAnimationFrame()で毎フレーム実行されます。
  この中で豆腐の頂点、パーティクル、3Dシーンを更新します。

  豆腐の各頂点は保存しておいた元の位置を基準に計算します。
  攻撃直後のsquishFactorによる揺れはフレームごとに減衰し、HPの減少に応じて表面の歪みも加わります。
  パーティクルは速度に応じて移動し、重力で落下します。寿命が尽きた粒子はシーンから取り除き、
  ジオメトリとマテリアルも解放します。

  ページ読み込み時にwindow.onloadからinit3D()とanimate()を開始します。


5. 起動方法と依存関係
----------------------
index.htmlをブラウザーで開くとゲームが起動します。Google Fonts、Tailwind CSS、Three.jsはCDNから
取得するため、初回表示時はインターネット接続が必要です。
ブラウザーによるlocalStorageや音声の制限を避けるには、VS CodeのLive ServerなどでローカルWebサーバーを
起動してアクセスする方法が適しています。効果音はユーザーがゲーム開始ボタンを押した後に有効になります。


6. 主な変更ポイント
--------------------
  - 次の豆腐の出現条件や強さを変更する: code_artifact.jsのSTAGE_TWO_TIERSとFINAL_BOSS_TIERS内の
    maxClearTimeMs、name、hp、color、roughness、metalness、scaleを変更します。
  - 攻撃力を変更する: code_artifact.jsのSKILLS内のdamage値を変更します。
  - フィーバーの倍率や時間を変更する: attack()とactivateFever()を確認します。
  - ステージ数を変更する: STAGE_TOTALとstageSequenceの初期化、次の相手を選ぶ処理を合わせて変更します。
  - ランクの基準を変更する: finishGame()内の合計時間条件を変更します。
  - 色、揺れ、点滅などを変更する: code_artifact.cssの該当スタイルやキーフレームを変更します。
  - 画面文言やUI部品を変更する: index.htmlを編集します。
